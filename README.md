# Edvaldo da Glória Mahesh — Portfólio académico

Portfólio independente desenvolvido em React + Vite, com design responsivo.

## Executar

```bash
npm install
npm run dev
```

Para produção: `npm run build`.

## Fontes e verificação

Dados institucionais fundamentados em referências públicas do ISUTC, apresentadas no website. A informação de que Edvaldo Mahesh frequentou a Université Saad Dahlab de Blida, na Argélia, juntamente com Helton General foi fornecida por terceiro e ainda necessita de confirmação documental.

Este website não é uma publicação oficial nem foi validado pelo docente. Não inclua novas credenciais académicas sem confirmação.
